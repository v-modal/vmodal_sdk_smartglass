# Implemented contracts

`core` exposes neutral immutable Kotlin records and ports. The app constructs one owner, a Meta gateway shared by speech/display, one authenticated VModal gateway, and the Android image preparer. Only `adapters/meta` imports DAT and only `adapters/vmodal` imports the VModal SDK. The boundary verification task checks imports, the resolved Maven artifact, core dependencies, and absence of MockDeviceKit from production release.

Authentication calls SDK `auth.me`, creates an identity-configured client, lists visible `vid_file` groups, and freezes the selected group's advertised numeric index version with account/stream/session generation. No default index version is invented. Standalone images are explicitly unsupported until validated.

Only a nonblank final transcript searches. Whitespace is normalized while the raw transcript is retained. Partials do not search; accepted finals are deduplicated per turn. The adapter follows Meta's documented first-final behavior; DAT1.0.1 has no public utterance-completion event. Whole-utterance semantics must pass physical P0. Segmented-final aggregation is currently unsupported and cannot be inferred from simulator success. Two turns with the same words produce two valid requests. Every asynchronous step checks the current generation and provenance. Display actions carry screen/session/request identities, so old callbacks cannot cancel or retry a new result.

The SDK request uses `searchVideo` with offset 0, limit 1, selected mode/group/stream/version and the complete transcript. The adapter adds no raw routes or extra pipeline selectors. Only the first returned row is mapped; an empty page is Empty even if total is positive. A malformed first row is TopHitUnresolvable, with no promotion of rank 2. SDK response order remains backend authority, with live ranking semantics still awaiting P0 proof.

Coordinate helpers are copied with attribution from the Android cookbook/full app. Filename aliases and exact `stream-filename-timestamp` item IDs are supported; arbitrary titles are not filenames. Existing timestamp semantics preserve leading zeroes, convert proven seconds forms to milliseconds, and leave absent values absent. Lookup sends one SDK `ImageUrlRecord` with `vid_img`; it invents no version field. The bulk join requires exactly one unique integral `input_index=0`, `found!=false`, and a nonblank signed URL. Missing or mismatched indices fail. Only HTTP 403/404/410 download failures re-resolve the same hit once, within the deadline. Temporary URLs never cross the adapter boundary.

The SDK transport bounds downloaded bytes at 8 MiB. The source recognizes JPEG/PNG/WebP signatures; Android preparation deliberately accepts JPEG/PNG only. Header inspection rejects invalid formats and sources above 24 megapixels before full decode. Sampled working allocations are bounded to four preview allocations (6 MiB by default), with explicit allocation checks; rotation/fit may briefly own multiple bounded bitmaps. The final fit preserves aspect ratio and orientation, is at most 600 pixels per side, 2 MiB encoded and 1.5 MiB decoded RGBA. Intermediates are recycled in `finally`; cancellation propagates.

One controller serializes state and display submissions. Default deadlines are 15 seconds listening, 20 seconds search/image/preparation and 5 seconds per display submission/cleanup operation. Each listening turn renews the Speech capability within the same shared DAT session: DAT retains its prior transcription StateFlow across stop/start, which could otherwise suppress identical final-only turns. Display remains attached. ShowingImage is published only after DAT accepts the current submission. Native actions are registered before submission returns because the wearer may click content immediately upon acceptance. MDK submission acceptance proves the transport contract; visible hardware rendering still requires a wearer. New turns clear old results. Background/logout/disconnect cancels collectors and work, clears when reachable and stops the session. Explicit Connect is required to resume.
